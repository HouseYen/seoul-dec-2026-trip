最終 16 個測試 × 桌機／手機，**32 通過、0 失敗**：

## 測試範圍與限制

- 使用本機真實 Chrome 的獨立暫存 profile；沒有修改個人 Chrome 或 Hermes 設定。
- 整合測試隔離第三方 Google Maps iframe，證明的是本站操作、產生的起終點和 URL；不是 Google 實際班次／路況證明。
- 視覺證據放在本機 `qa-artifacts/`，不為清理而刪除；Git 忽略截圖與 `test-results/`。
- 機票指定日期結帳總價、飯店空房／含稅價、出發日營業／尺碼／活動檔期仍未核實，已在頁面明列。
- `node --check`、來源 ledger、`git diff --check` 另行執行。正式部署必須在推送後核對遠端 commit、Pages build、HTTP／實際資產與線上瀏覽器行為；不能只憑本文件宣稱上線。
